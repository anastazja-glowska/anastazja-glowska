## What I Work On

### Java & Platform Modernization

I work on modernization of enterprise applications, including migrations to **Java 21 and newer Spring Boot versions**, dependency upgrades, persistence-layer changes and production configuration.

The goal is not simply to upgrade frameworks, but to **reduce technological debt, improve maintainability, remove legacy constraints and create a stronger foundation for future development**.

### Distributed Backend Systems

I design and develop backend services using **Apache Kafka, asynchronous communication, microservices and event-driven architecture**.

I focus on clear service boundaries, predictable data flows and failure handling so that integrations between systems remain **reliable, understandable and maintainable as the platform evolves**.

### Production Engineering

I work with systems where production stability matters as much as feature delivery.

This includes designing APIs and backend processes with **failure scenarios, data consistency, observability, security and maintainability** in mind.

The result is software that can be changed and extended with lower operational risk instead of accumulating fragile dependencies over time.

### Data & Persistence

I work with **PostgreSQL, Oracle, Hibernate/JPA, Flyway and Redis**, designing persistence solutions that support both business requirements and long-term system maintainability.

I pay particular attention to schema evolution, transactional boundaries and the impact of persistence decisions on application behaviour in production.

### Testing & Delivery

I use automated testing as part of system design rather than only as a final verification step.

My testing stack includes **JUnit, Mockito, Testcontainers, WireMock and REST Assured**, covering business logic as well as integrations and infrastructure-dependent behaviour.

Combined with Maven, Docker and CI/CD pipelines, this helps make changes **safer to release, easier to validate and less dependent on manual verification**.

## Engineering Impact

The systems and modernization work I contribute to are aimed at:

- reducing technical debt and legacy constraints,
- increasing production reliability and maintainability,
- enabling safer upgrades and future feature development,
- improving confidence in integrations through automated testing,
- making distributed system behaviour easier to understand and operate,
- reducing the risk associated with changes in business-critical backend systems.

I care not only about whether software works today, but whether **another engineer can safely understand, modify and operate it months or years later**.
